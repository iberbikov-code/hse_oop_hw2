# Система управления рецептами

## Описание

Консольное приложение для управления рецептами, масштабирования порций и автоматической генерации списков покупок. Проект реализован с использованием объектно-ориентированного программирования (ООП) на Python и полностью покрыт unit-тестами с помощью библиотеки `pytest`.

### Основные возможности

- Создание и хранение ингредиентов с валидацией количества
- Формирование рецептов с автоматическим объединением одинаковых ингредиентов
- Масштабирование рецептов на произвольное количество порций
- Поддержка диетических рецептов с указанием категории (веган, кето, без глютена и т.д.)
- Автоматическая генерация списка покупок с суммированием одинаковых продуктов из разных рецептов
- Объединение нескольких списков покупок в один

### Структура проекта
* `recipes/` — исходный код на Python (реализация классов: Ingredient, Recipe, ShoppingList, DietaryRecipe).
* `test_recipes/` — авто-тесты для всех классов
* `requirements/` - зависимости проекта
* `.gitigore/` - исключения для Git
* `README/` - описание и инструкция по запуску проекта

### Установка и запуск проекта
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/iberbikov-code/hse_oop_hw2.git
   ```
2. Перейдите в папку проекта:
   ```bash
   cd hse_oop_hw2
   ```
3. Установите зависимости проекта:
   ```bash
   pip install -r requirements.txt
   ```
4. Для запуска тестов введите:
   ```bash
   pytest
   ```
   (если термиинал не распознает команду pytest)
   ```bash
   python3 -m pip install pytest
   python3 -m pytest
   ```
